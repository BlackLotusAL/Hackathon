# 赛事系统交付与联调计划

总验收截止为 **2026 年 11 月 20 日**。主办方赛事负责人验收三个系统的同机部署、Codehub 仓库与权限，以及报名、天梯、初赛和决赛全流程。

## 一、交付物

| 交付物 | 负责人 | 交付内容 |
| --- | --- | --- |
| Portal 选手门户 | Portal 负责人 | SSO 登录、报名和队伍管理、题目和下载、赛程进度、天梯、对局回放及比赛结果 |
| Contest 服务、管理后台及裁判镜像 | Contest 负责人 | 对决的 HTTP 提交和查询，初赛 XLSX 交接，单局调度与复核、确认和导出，带标签和 digest 的赛段裁判镜像 |
| Arena 服务与三语言构建模板 | Arena 负责人 | 固定版本，构建和隔离运行 Python、C++、Java Bot，提供任务提交、单局状态和整体运行统计，发布共享归档 |
| Codehub 赛事仓库与权限 | Codehub 管理员 | 赛事届次组、平台仓库、材料和基准 Bot 仓库、私密地图仓和单队代码仓。主办方管理锁仓，队员仅有本队仓的写权限 |
| 初赛和决赛选手材料包 | Contest 负责人 | 同版引擎、三语言 SDK 和模板、基准 Bot、本地练习与复核工具、示例回放 |

| 11 月 16 日 | 单局执行 | Arena 负责人 | Contest、Codehub | 仓库权限可用，三种语言的 Bot 可构建并在隔离环境运行，提交幂等，终态可查询时归档齐全。 |
