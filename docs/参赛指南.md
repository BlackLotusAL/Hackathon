# 参赛指南

## 一、下载材料包

打开门户的「题目规则」页面，下载选手材料包并解压。阅读其中的 `README.md`，按你使用的语言配置好环境。

> 此处放「题目规则」截图，标出材料包下载入口。

## 二、提交代码

1. 在门户的「队伍管理」中复制主办方分配给本队的 Codehub 仓库地址。在材料包根目录执行下面的命令，Git 会按仓库名在 `bots/` 下创建目录，例如 `bots/team001`。

   ```bash
   git -C bots clone "<本队仓库地址>"
   ```

   > 此处放「队伍管理」截图，标出本队仓库地址。

2. 在 `bots/` 目录中挑选一个以 `my_bot_` 开头的模板，将其中的文件复制到刚克隆的本队仓库根目录，再在此基础上修改代码。

3. 在材料包根目录运行本地对战命令。第一个参数指定要测试的 Bot 目录，`--opponent` 指定 `bots/` 中的基准 Bot（`bot001`、`bot002` 或 `bot003`）。

   ```bash
   # 用材料包里的 Python 模板对战
   python -m engine bots/my_bot_python --opponent bot002
   
   # 提交前用本队仓库的代码对战
   python -m engine bots/team001 --opponent bot002
   ```

   注意把 `team001` 替换成本队的仓库名。

1. 进入 `bots/` 下的本队仓库，执行下面的命令，将代码推送到 Codehub。

   ```bash
   git add .
   git commit -m "提交参赛代码"
   git push origin HEAD:refs/heads/master
   ```

   在 Codehub 的 `master` 分支看到本次提交，即视为交卷成功。正式比赛以锁仓时 `master` 分支上的版本为准。

## 三、天梯对决

天梯开放后，请先确认本队 `master` 分支上已有代码。打开「天梯榜」，选择其他队伍或基准 Bot 发起挑战。

> 此处放「天梯榜」截图，标出选择对手和发起挑战的位置。

每场天梯对决使用同一张随机地图进行两局，第二局双方交换起始位置（换边）。同一时间内，本队只能发起一场对决。

## 四、对局回放

天梯对局结束后，前往「对局记录」，筛选天梯场次，找到对应的挑战，点选想查看的一局，天梯回放仅交手的双方队伍可见。

下载并解压选手材料包后，可在浏览器打开 `replay.html` 查看固定加速区和示例对局。[本地回放页面](../player-kit/replay.html)
